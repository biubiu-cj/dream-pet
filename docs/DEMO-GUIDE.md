# DreamPet 比赛演示脚本（约 5 分钟）

> 演示前确认：后端已配置 `LLM_API_KEY`（真实 AI 模式），前端已启动。
> 核心卖点：**长期记忆 + 主动陪伴 + 成长反馈 + 用户意图识别**，且全程无图片/语音生成模型。
>
> **重要**：第六步的「欢迎回来」默认需要距上次聊天超过 30 分钟才生成。
> 演示前请用 `GREETING_IDLE_MINUTES=0` 启动后端（例如 `GREETING_IDLE_MINUTES=0 mvn spring-boot:run`），
> 否则重启后进入聊天页看不到新的欢迎语。

## 开场（20 秒）

「DreamPet 是为 6~10 岁孩子设计的 AI 梦想养成伙伴。每一次陪伴，都是一次成长。
孩子有一个会记住他、主动陪他探索、还会慢慢长大的伙伴。整个产品只调用文本大模型，宠物形象全部来自本地素材 + CSS 动画，不做实时生图。」

## 第一步：创建伙伴（45 秒）

1. 打开首页 → 注册或点「一键体验」；
2. 选择**小狐狸**，起名 **星星**，性格选**活泼好奇**；
3. 点击创建 → 展示伙伴主页：星星出现、等级 Lv.1、成长进度条。

讲解：「不需要预选兴趣，孩子想聊什么就聊什么——伙伴会在聊天中自然记住话题。」

## 第二步：第一次互动（60 秒）

1. 进入聊天，输入：**「我很喜欢恐龙，我以后想成为科学家。」**
2. 星星回应并引导探索恐龙话题；
3. 停留 1~2 秒后说明：「后台已经从这句自由聊天中提取出话题『恐龙』和梦想『想成为科学家』，
   写入话题记忆与重要事件记忆——这些不是存在浏览器里，而是数据库表 `user_interests` / `memories`。」

## 第三步：生成今日任务（40 秒）

1. 返回首页或任务页，点「让伙伴设计新任务」；
2. 出现基于恐龙兴趣的任务，如**「恐龙小侦探：找出霸王龙和三角龙的三个不同之处」**；
3. 讲解：「任务由 TaskAgent 结合聊天里自然形成的话题与历史任务生成，并通过 JSON 结构校验；奖励数值由后端截断控制，AI 无权决定。」

## 第四步：完成任务（50 秒）

1. 打开任务详情 → 输入孩子的发现（如「霸王龙的牙齿很尖」）→ 完成；
2. 播放经验增长/升级动画，星星给出个性化祝贺；
3. 讲解：「防止重复领取经验用了数据库条件更新；升级、阶段切换完全由后端 GrowthService 计算。」

## 第五步：成长日记（40 秒）

1. 打开成长日记/成长档案；
2. 依次展示：创建伙伴 → 第一次聊天 → 表达兴趣 → 完成任务 → 成长事件；
3. 讲解：「这就是孩子和伙伴共同经历的成长时间线。」

## 第六步：重启见证记忆（60 秒，高潮）

1. **停止后端进程**（或刷新/重新打开浏览器），重新启动后端；
2. 重新进入聊天页；
3. 星星主动说：「欢迎回来！我是星星！上次我们一起完成了『恐龙小侦探』，今天还想继续我们的恐龙冒险吗？」
4. 讲解：「这段欢迎语不是写死的——它读取了数据库中的任务、兴趣和事件记录后生成。这就是长期记忆。」

## 收尾（20 秒）

「DreamPet 还内置了儿童安全防护：隐私信息、危险话题会温和拦截并引导孩子找可信任的大人；
不设计签到惩罚、不做消费诱导。所有对话由真实文本大模型生成，并带有意图识别：孩子说『好无聊』会推荐任务，
说『还记得上次吗』会基于真实记忆回忆，情绪低落时先安抚。模型超时或限流时会给出明确提示并可重试。」

## 演示前检查清单

- [ ] 后端 `http://localhost:8080/api/system/info` 正常
- [ ] 前端 `http://localhost:5173` 正常
- [ ] 后端环境变量 `LLM_API_KEY` 已配置，`/api/chat` 能正常返回
- [ ] 数据库干净或已准备好体验账号
- [ ] 网络可访问 `LLM_BASE_URL`；若模型超时，页面会给出友好提示，可直接重试
- [ ] 浏览器缩放 100%，窗口为移动端尺寸观感最佳
