## 2. 自动化测试明细（20 个）

**集成测试 `DreamPetFlowTest.fullDemoFlow`**（1 个）：
系统信息 → 游客注册 → 创建伙伴（**无需预选兴趣**，初始经验/阶段）→ 聊天 + 异步记忆提取（话题/画像）→
任务生成与幂等 → 完成任务 + 重复完成被拒 → 经验/等级计算 → 历史恢复 → 成长概览/事件/记忆列表 →
**更换伙伴物种（rabbit，含非法物种 400 校验）** → **开始任务（pending → in_progress）** →
**按天汇总（经验总和一致、聊天流水合并、高光含任务完成）** → **成就徽章（解锁项正确）** →
用户隔离（404）→ 重新进入欢迎语（基于真实数据并写入历史）；另含 `/api/health` 检查。

## 5. 失败处理实测

| 场景 | 客户端结果 | 服务端日志 |
|---|---|---|
| 无效 Key | `HTTP 502 {"code":502,"message":"AI 服务认证失败，请检查 API Key 配置"}` | `status=401, type=AUTH, model=deepseek-chat`（无 Key、无正文） |
| 未配置 Key | `HTTP 503 {"code":503,"message":"AI 服务还没有配置好，请联系管理员"}` | 启动时 ERROR 提示配置缺失 |
| 超时 / 上游 5xx | 自动重试 1 次后返回 504 / 502 | 记录错误类型与状态码 |
| 模型返回空内容 | 502「AI 伙伴没有回应，请再说一次」 | type=EMPTY |
| 任务生成非 JSON | 使用服务端兜底任务，不中断流程 | 警告日志 |

## 7. 开发过程中发现并修复的问题

| 问题 | 修复 |
|---|---|
| H2 PostgreSQL 模式不支持 `AUTO_INCREMENT` | 改用 `GENERATED BY DEFAULT AS IDENTITY` |
| `MockLlmClient` 对 `Set` 调用 `replaceAll` 无法编译 | 改为 stream + `Collectors.toSet()`（该客户端现已移至测试源码） |
| 两处 DTO 使用不存在的全参构造 | 改为无参构造 + setter |
| 集成测试异步断言存在竞态 | 轮询条件改为等待兴趣与画像同时落库 |
| 反复请求欢迎语导致聊天记录重复 | 10 分钟内不再重复生成；更长时间后仍可问候 |
| 旧进程占用导致 jar 打包为不可执行文件 | 停止进程后重新打包并校验 `Main-Class` |
| 意图规则漏识别「我以后想成为…」 | 扩展梦想意图正则 |
| Windows curl 发送中文出现编码错误 | 使用 Node 脚本进行联调与冒烟 |
